# Clinical Genomics SQL Database: Real TCGA-LUAD Data

## Overview
A relational database built from real patient data from The Cancer Genome Atlas (TCGA) Lung Adenocarcinoma (LUAD) cohort. This project demonstrates end-to-end SQL database design, population with real clinical and genomic data, and 8 analytical queries addressing clinically relevant questions about lung cancer patient outcomes.

## Why This Matters
Relational databases are the backbone of clinical data management in drug development and healthcare. This project directly mirrors real-world workflows:

- **Clinical trial databases** — patient data, treatment assignments, and outcomes are stored in relational systems (Medidata Rave, Oracle Clinical)
- **Genomics data warehouses** — TCGA, COSMIC, and internal pharma genomics platforms use SQL to store and query large-scale datasets
- **Real world evidence** — EHR and claims databases are queried using SQL to generate evidence for regulatory submissions
- **Biomarker analysis** — SQL joins enable rapid patient stratification by molecular subtype, stage, and clinical factors

## Data Source
- **Database:** The Cancer Genome Atlas (TCGA)
- **Project:** TCGA-LUAD (Lung Adenocarcinoma)
- **Access:** Public — https://portal.gdc.cancer.gov/
- **Download method:** TCGAbiolinks Bioconductor package
- **Patients:** 118 real lung adenocarcinoma patients
- **Data types:** Clinical outcomes, molecular subtypes from RNA-seq PCA clustering

## Database Schema

```
cancer_types ──── patients ──── survival_outcomes
                      │
                      └──── molecular_subtypes
```

### Tables
| Table | Description | Key Fields |
|---|---|---|
| `cancer_types` | Cancer type reference | cancer_code, tissue_origin, ICD10 |
| `patients` | Real TCGA clinical data | age, gender, stage, smoking, vital_status |
| `molecular_subtypes` | RNA-seq derived subtypes | subtype, PC1, PC2 coordinates |
| `survival_outcomes` | Real survival data | OS_days, OS_years, vital_status |

## Analytical Queries

| Query | Question | SQL Concepts Used |
|---|---|---|
| 1 | Cohort demographics overview | Aggregate functions, JOIN |
| 2 | Survival and mortality by tumor stage | GROUP BY, CASE WHEN, ORDER BY |
| 3 | Survival by molecular subtype | Multi-table JOIN, aggregation |
| 4 | Smoking history and survival outcomes | GROUP BY, conditional aggregation |
| 5 | High-risk patient identification | WHERE filters, multi-table JOIN, LIMIT |
| 6 | Gender differences in survival | Conditional aggregation, GROUP BY |
| 7 | Molecular subtype distribution by stage | Multi-dimensional GROUP BY |
| 8 | Long-term survivor characteristics | Subquery, percentage calculation |

## Key Findings from Real TCGA Data
- Stage I patients have significantly better survival than Stage IV — confirming the clinical importance of early detection
- Molecular subtypes derived from unsupervised RNA-seq clustering show distinct survival outcomes — supporting their clinical relevance as prognostic biomarkers
- Never smokers show better survival outcomes than current smokers — consistent with published LUAD literature
- Female patients show better survival outcomes than male patients — consistent with known sex differences in LUAD biology

## How to Run

### Prerequisites
This project requires the TCGA data files generated by the companion project:
- `tcga_luad_clinical_processed.csv`
- `tcga_luad_subtype_assignments.csv`

These are available in the [tcga-lung-cancer-analysis](https://github.com/GokulSelvaraj-Scientist/tcga-lung-cancer-analysis) repository.

### Step 1 — Install R packages
```r
install.packages(c("RSQLite", "DBI", "ggplot2", "dplyr", "tidyr", "RColorBrewer"))
```

### Step 2 — Place data files in same directory
Copy `tcga_luad_clinical_processed.csv` and `tcga_luad_subtype_assignments.csv` into this folder.

### Step 3 — Run analysis
```r
setwd("path/to/genomics-sql-analysis")
source("tcga_sql_analysis.R")
```

## Technical Stack

- **SQL:** Schema design, multi-table JOINs, subqueries, CASE WHEN, aggregate functions
- **R:** RSQLite, DBI for database connectivity; ggplot2, dplyr for analysis and visualisation
- **Data:** Real TCGA-LUAD clinical and molecular data
